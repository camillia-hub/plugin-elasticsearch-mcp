# Elasticsearch MCP

Searches an Elasticsearch cluster. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/@elastic/mcp-server-elasticsearch

Installs from the Camillia hub as `elasticsearch-mcp-2b8219`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
